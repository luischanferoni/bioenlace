# Módulo Animal

BC módulo-primero para identidad y representación de animales, separado de `Person/Representation` y de `Clinical`.

## Capas previstas

- `Application/`: casos de uso, servicios y semillas del módulo.
- `Domain/`: entidad, catálogos y puertos propios.
- `Infrastructure/`: persistencia y adaptadores externos.

El vínculo persistente con el tutor y los catálogos iniciales requieren confirmar el MVP. No agregar aún modelos ActiveRecord, migraciones ni rutas.
