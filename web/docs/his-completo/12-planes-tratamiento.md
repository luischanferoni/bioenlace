# Planes de tratamiento (care plans)

**Madurez orientativa:** 3,3 / 4 (~83 %)

## Lo que tenemos

- [x] Plan vinculado al paciente y, cuando corresponde, a la atención que lo originó.
- [x] Actividades (medicación, controles, hábitos) con estados.
- [x] Vista de planes activos y recordatorios en el dispositivo del paciente.
- [x] Hub Control/Seguimiento: tratamiento, condición y controles recomendados (protocolos Nación/Provincia).
- [x] Renovar o ajustar medicación y consulta por mensaje desde el plan (un profesional responde).
- [x] Cierre de problemas y planes al guardar la captura (agudos; crónicos no se cierran solos).
- [x] Dashboard de adherencia para el equipo (porcentaje de actividades cumplidas).
- [x] Rama automática tras un cuestionario de seguimiento (alerta al equipo o mensaje educativo).
- [x] Al alta hospitalaria, seguimiento programado (no es el alta clínica).

## Lo que falta

- [ ] Outcomes clínicos ligados a la adherencia (no solo tareas marcadas).
- [ ] Integración automática con dispensación o laboratorio de controles.
- [ ] Planes generados o ajustados por IA con validación médica explícita.
- [ ] Versionado y auditoría regulatoria de cambios del plan.
- [ ] Materializar un plan preventivo al aceptar un control de perfil (hoy es sugerencia).
- [ ] Continuidad ambulatoria explícita al alta (nuevo plan crónico) como flujo en pantalla.
