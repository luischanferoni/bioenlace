# Servicios de salud (oferta del centro)

**Madurez orientativa:** 3,2 / 4 (~80 %)

**Servicio** = oferta asistencial del **efector**, no la especialidad del profesional ni un acto SNOMED. Glosario: [glosario-servicio-pes-acto.md](../producto/glosario-servicio-pes-acto.md).

## Lo que tenemos

- [x] Catálogo de servicios institucionales por efector.
- [x] Profesional asignado a efector y servicio (PES) para agenda y atención.
- [x] Turnos y atenciones ambulatorias ligados al servicio del centro.
- [x] Sesión operativa (efector, servicio, clase de atención) para el personal.
- [x] Tipología de oferta y puente a actos (capacidad por reglas + línea servicio×acto).
- [x] Pedido de estudio o práctica: el paciente elige el **acto** y luego la oferta del centro que lo realiza.
- [x] Política de teleconsulta por servicio (ninguna / todas / algunos motivos).
- [x] Reserva por medicina clínica; especialista con derivación vigente.

## Lo que falta

- [ ] Reglas de cobertura y autorización por financiador en todos los flujos.
- [ ] Capacidad instalada y restricciones por recurso físico (salas, equipos).
- [ ] Reportes de producción por servicio unificados para dirección médica.
