# Fase 02 — Asignación por AdminEfector y REFEPS

## Objetivo

Mantener la búsqueda/invitación bajo control del AdminEfector y exigir habilitación profesional antes de asignar capacidades clínicas.

## Checklist

- [ ] Resolver profesional por Persona existente; no crear cuentas duplicadas por invitación.
- [ ] Al asignar rol clínico, verificar REFEPS con matching de identidad, profesión y jurisdicción.
- [ ] Diferenciar coincidencia, no encontrado, respuesta temporalmente indisponible y discrepancia de datos.
- [ ] Bloquear rol clínico hasta confirmación; permitir revisión manual con auditoría.
- [ ] No requerir REFEPS para asignación AdminEfector ni para administrar el centro.
- [ ] Aplicar la misma regla cuando AdminEfector se incorpora a sí mismo a un servicio clínico.
- [ ] Restringir la búsqueda a datos identificatorios mínimos y auditar consultas/cambios.

## Criterio de salida

Ningún usuario obtiene rol clínico por alta de identidad, invitación o rol AdminEfector sin validación REFEPS aprobada.
