# Fase 5 — El AdminEfector agrega al profesional + push

## Objetivo

Que un profesional de una organización ajena entre por alta del AdminEfector (sin pago) y reciba notificación.

## Entregables

- Acción de admin para vincular una Persona existente al efector como profesional (pool).
- Push notification al dispositivo del profesional cuando es agregado.
- El efector aparece en la lista de selección sin re-login.

## Decisiones a cerrar

- Cómo identifica el admin al profesional (documento/email).
- Flujo si el profesional aún no creó su cuenta de identidad (el admin le pide crearla y avisa cuando está).

## Criterios de aceptación

- Agregar profesional no exige pago.
- El push llega a la app y el efector queda disponible.
