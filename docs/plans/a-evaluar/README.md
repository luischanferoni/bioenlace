# A evaluar — notas previas a un plan

Carpeta para **análisis que todavía no son un plan**: no tienen fases, ni checklist, ni orden
de ejecución. Existen para no perder la evidencia hasta que haya tiempo de decidir si
justifican un plan propio.

## Reglas

1. Cada documento responde: **qué se midió, qué no se sabe todavía y qué habría que averiguar**
   antes de planificar.
2. Si se decide planificar, se abre `plans/<slug>/` y el documento se borra o se convierte en
   su `overview.md`.
3. Si se descarta, se anota la razón acá y el documento se borra.
